# M-Test 入力アプリ

iPadで M-Test（身体の動きのチェック）の結果をタッチで入力し、Googleスプレッドシートに蓄積するアプリです。
Wi-Fiがない場所でも入力・保存ができ、ネットにつながったときに送信します。Excel（.xlsx）への書き出しもできます。

## フォルダの中身

| ファイル | 内容 |
|---|---|
| `index.html` / `css/` / `js/` | 入力画面（PWA） |
| `js/config.js` | チェック項目・種目・ポジションの定義（項目を変えるときはここを編集） |
| `sw.js` / `manifest.webmanifest` / `icons/` | オフラインで動かすための仕組みとアイコン |
| `gas/Code.gs` | Googleスプレッドシート側の受け口（Google Apps Script） |
| `tools/make_icons.py` | アイコンを作り直すためのスクリプト |

## 1. Googleスプレッドシートの準備（最初に1回）

1. Googleドライブで新しいスプレッドシートを作る（名前の例：`M-Test データ`）
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている `コード.gs` の中身をすべて消し、`gas/Code.gs` の中身を貼り付けて保存（💾）
4. 上の関数の選択欄で **`setup`** を選び、**実行** を押す
   - 初回は「承認が必要です」と出るので、自分のアカウントを選んで許可する
   - 「このアプリは Google で確認されていません」と出たら **詳細 → （プロジェクト名）に移動** を押す（自分で作ったスクリプトなので問題ありません）
5. 下の **実行ログ** に「準備ができました（合言葉：なし）」と出ればOK
6. 右上の **デプロイ → 新しいデプロイ** を押す
   - 種類の選択（⚙）で **ウェブアプリ** を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - **デプロイ** を押し、表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）を控える

> 「アクセスできるユーザー：全員」は、ログインなしでiPadから送信できるようにするための設定です。
> 受け口にはデータを読み出す機能がないため、URLを知られてもスプレッドシートの中身は見られません。
> ただし、URLを知っている人はデータを書き込めてしまうので、**URLは人に教えず、iPadの設定画面以外に貼らないでください**。

### スプレッドシートの共有について
- 共有は **自分だけ**、または必要な人だけに絞ってください。「リンクを知っている全員」にはしないでください。

### 合言葉（任意）
初期状態では合言葉なしで、URLだけで送信できます。守りを強くしたいときや、URLが漏れたかもしれないときは、合言葉を有効にできます。

- **有効にする／作り直す**：Apps Script の画面で **`enableSecret`** を実行 → 実行ログに出た合言葉を、iPadの設定画面の「合言葉」欄に入力
  （有効にした後は、合言葉が一致しない送信は受け付けません。作り直すと古い合言葉は使えなくなります）
- **なくす**：**`disableSecret`** を実行（iPadの合言葉欄は空欄に戻してかまいません）
- URLが漏れたときは、合言葉を有効にするか、**新しいデプロイを作ってURLを変える**（古いデプロイは「デプロイを管理」からアーカイブ）と確実です

### `gas/Code.gs` を修正したとき
**デプロイ → デプロイを管理 → ✎（編集）→ バージョン：新バージョン → デプロイ** で反映します（URLは変わりません）。

## 2. iPadへのインストール

1. iPadの **Safari** で、入力画面のアドレス（GitHub Pages のURL）を開く（このときだけネットが必要）
2. 共有ボタン［□↑］→ **ホーム画面に追加**
3. ホーム画面の **M-Test入力** アイコンから起動する
4. 右上の **設定** を開き、次を入力して **保存**
   - このiPadの記号：`A`（2台目以降は `B`、`C`…）
   - 送信先のURL：手順1-6で控えたURL
   - 合言葉：空欄のまま（スプレッドシート側で合言葉を有効にした場合のみ入力）
5. **接続テスト** で「✓ 接続できました」と出れば完了

> 必ず **ホーム画面のアイコンから** 使ってください。Safariのタブで使うと、しばらく使わないうちにiPadが保存データを消すことがあります。
> iPadには **パスコード** を設定してください（送信前のデータに氏名が含まれるため）。

## 3. 使い方

1. **基本情報**：氏名・生年月日・性別・種目・ポジションを入力 → **チェック開始**
   - 2回目以降の人は、氏名を数文字打つと候補が出ます。選ぶと残りの項目が自動で入ります
2. **チェック**：調べた順に入力
   - **確認**：その動作を調べ終わったら押す（異常なしのとき）
   - **右・左／前屈・後屈**：異常があった方向を押す（確認済も自動で付きます）
   - もう一度押すと解除されます
3. **保存**：未確認の動作があれば知らせます → 保存すると次の人の入力画面に戻ります

- 測定番号は自動で付きます（例：`20261012-A-003` ＝ 日付・iPadの記号・その日の連番）
- 入力途中でアプリを閉じても、続きから再開できます
- 上部の **未送信 ○件** を押すと、すぐに送信します（ネットにつながると自動でも送信されます）

### データ管理（右上）
- **Excelに書き出し**：iPad内のデータを .xlsx で書き出し、AirDrop などでPCへ送れます
- 送信が終わったデータは、初期設定ではiPadから自動で削除されます（設定で変更可）。
  過去のデータはスプレッドシートから取り出してください（ファイル → ダウンロード → Microsoft Excel）
- 候補表示用の基本情報は「候補（基本情報）をすべて削除」で消せます

---

## 4. 記録される列（1回の測定＝1行、全96列）

`測定番号, 測定日時, 端末, 氏名, 生年月日, 年齢, 性別, 種目, ポジション`
に続けて、29動作それぞれについて `部位_動作_確認済`, `部位_動作_右（前屈）`, `部位_動作_左（後屈）` が並びます。
値は **1＝あり／0＝なし** です。

---

## 5. 個人情報・秘密の情報の扱い

- 送信先のURL（と、使う場合は合言葉）は **iPadの中にだけ** 保存し、プログラムやGitHubには含めません
- `.gitignore` で、Excel・CSVなどのデータファイルや秘密のファイルをGitHubに上げないようにしています
- 動作確認には架空の氏名だけを使い、実際の選手のデータはリポジトリに入れないでください

## 6. 画面を修正したとき

`sw.js` の `CACHE` の番号を上げてください（例：`mtest-input-v1.0.1`）。
iPadはネットにつながったときに新しい画面を取得し、次回の起動から反映されます。

## 7. Macで動作確認する

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```
ブラウザで http://127.0.0.1:8765/ を開きます。
